# Arabic Handwriting Recognition – Graduation Project

## Abstract
Arabic handwritten character recognition is a challenging task due to the cursive nature of Arabic script, where character shapes vary depending on their position within a word. Additional challenges include diverse handwriting styles, diacritical marks, and overlapping characters.

This work represents a B.Sc. graduation research project in Data Science and Artificial Intelligence, aiming to enhance the accuracy of Arabic handwritten character recognition using machine learning, deep learning, and natural language processing techniques. The system was trained on a diverse dataset to improve generalization across different handwriting styles.

The proposed approach supports applications such as document digitization, historical manuscript preservation, and assistive technologies for visually impaired individuals.
